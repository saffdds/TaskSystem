# 🛡️ TaskSystem

> Un'alternativa Open Source a riga di comando (CLI) al Gestione Attività di Windows.

Benvenuto in **TaskSystem**, il monitor di sistema leggero, veloce e senza fronzoli, progettato per chi ama il controllo totale tramite terminale. Ispirato alla semplicità del MS-DOS e alla potenza della CLI moderna.

---

## ✨ Caratteristiche principali

*   🚀 **Leggero**: Gira interamente nel terminale senza pesare sulla GPU.
*   📊 **Monitor in Tempo Reale**: Visualizza i processi ordinati per consumo di RAM (i più "golosi" in alto!).
*   🗡️ **Sistema Hunter**: Include il comando speciale `/kill` per terminare i processi istantaneamente.
*   🌍 **Cross-Platform**: Funziona su Windows (PowerShell/CMD) e Linux (WSL/Ubuntu).

---

## 🎮 Come si usa

Una volta avviato il programma, vedrai la lista dei processi aggiornarsi. 

### Il Comando `/kill`
Ispirato a Minecraft, puoi abbattere qualsiasi processo fastidioso digitando:
`/kill <PID>`

*Esempio: per chiudere un programma con PID 6500, scrivi `/kill 6500` e premi Invio.*
